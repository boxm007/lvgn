# 🧭 Long Voyage (การเดินทางอันยาวนาน)

**Long Voyage** คือเว็บบอร์ดเกมสวมบทบาท (Roleplay & Text-Adventure Engine) แนววางแผนและเล่าเรื่องที่ขับเคลื่อนด้วยระบบ AI ปริศนา 4 ขั้นตอน (4-Stage Pipeline) ร่วมกับกลไกหน้าเต๋านำโชค (Fate Engine D20) และหน้าจอธีมสีเข้มสไตล์ **Khuiai (คุยไอ)** ที่ตอบสนองอย่างรวดเร็ว

---

## ✨ คุณสมบัติเด่น (Features)

1. **4-Stage DeepSeek Pipeline (ระบบประมวลผล AI 4 ขั้นตอน):**
   * **Stage 1 (Context Extractor):** สแกนความตั้งใจของผู้เล่นร่วมกับข้อมูลโลกและไอเทมในตัว (Lean Bible Index) เพื่อระบุค่าพลังในการทอยเต๋า
   * **Fate Engine (D20 Dice Roll):** ทอยลูกเต๋าเชิงฟิสิกส์ 20 หน้าแบบโปร่งใส [ล้มเหลวร้ายแรง, ล้มเหลว, สำเร็จ, สำเร็จอย่างงดงาม] ร่วมกับ Stat Modifier เพื่อกำหนดผลลัพธ์
   * **Stage 2 (Reasoning GM):** ประเมินผลกระทบเชิงกลไก จิตวิทยา ความสัมพันธ์ (-5 ถึง +5) และตรวจสอบความลับ (Secret Notes)
   * **Stage 3 (Storyteller):** บรรยายฉากและประพันธ์ภาษาร้อยแก้วภาษาไทยอันประณีตและเปี่ยมอารมณ์ด้วยเทคนิค *Prose Craft (Show Don't Tell, Subtext)*
   * **Stage 4 (Memory Writer):** เขียนสรุปความทรงจำและอัปเดตฐานข้อมูลโดยไม่ส่งผลกระทบต่อความเร็วการตอบกลับของตัวเกมหลัก
2. **6 โหมดสไตล์การเล่าเรื่อง (6 Style Modes):**
   * 🔥 **Drama (ดราม่า):** บีบคั้น มีมิติอารมณ์และจิตวิทยา
   * 🌙 **Dark (ดาร์ก):** หนักหน่วง โลกไม่ปรานี ไร้ Plot Armor
   * ☀️ **Warm (อบอุ่นหัวใจ):** มิตรภาพและความหวังท่ามกลางหิมะ
   * ⚔️ **Adventure (ผจญภัย):** กระชับ ฉับไว แอ็กชันตื่นเต้น
   * 🩸 **Tactical/Gritty (ยุทธวิธี):** ตรรกะเหตุและผลลัพธ์ที่สมจริง
   * 🎭 **Slice of Life (เรียบง่าย):** บรรยากาศผ่อนคลายและชีวิตประจำวัน
3. **Folder-Based Isolated Saves (โฟลเดอร์เซฟแยกอิสระ 100%):**
   * บันทึกข้อมูลการเล่นแต่ละรอบแยกโฟลเดอร์อย่างสมบูรณ์แบบที่ `data/saves/<slot_id>/` ไม่มีทางที่การเซฟหรือการเล่นหลายคนจะปนเปื้อนหรือทับซ้อนกัน
4. **Dynamic NPC Discovery (บันทึกตัวละครลง Worldbook):**
   * หากมีตัวละครใหม่ปรากฏขึ้นในเนื้อเรื่อง ระบบจะขึ้นกล่องคำถามให้คุณเลือกว่าจะจดจำลง Worldbook/Codex เพื่อสร้างหลอดความสัมพันธ์ต่อ หรือจะปล่อยเป็นเพียงตัวประกอบทั่วไป
5. **Worldbook / Lorebook AI Auto-Extractor:**
   * สามารถนำเข้าไฟล์การ์ดตัวละครหรือลอเร่โลกดิบ (.json, .txt, .md) สั่งให้ AI สรุปและกรอกฟอร์มสร้างโลกโดยละเอียดให้แบบอัตโนมัติ

## 🛠️ ขั้นตอนการติดตั้งและเปิดใช้งาน (Setup & Run)

### วิธีที่ 1: ดับเบิ้ลคลิก 1-Click สำหรับ Windows (แนะนำ)
* เพียงดับเบิ้ลคลิกที่ไฟล์ **`start.bat`**
* ระบบจะทำการตรวจสอบ Node.js, ติดตั้ง Dependencies และเปิดหน้าเว็บ `http://localhost:3000` ให้โดยอัตโนมัติ

---

### วิธีที่ 2: รันผ่านคำสั่ง Terminal / Command Prompt
1. **ติดตั้ง Dependencies:**
   ```bash
   npm install
   ```
2. **สตาร์ทเซิร์ฟเวอร์:**
   ```bash
   npm start
   ```
   หรือ
   ```bash
   node server/index.js
   ```
3. เปิดบราวเซอร์แล้วเข้าใช้งานที่: **[http://localhost:3000](http://localhost:3000)**

เปิดบราวเซอร์แล้วเข้าใช้งานได้ทันทีที่: **[http://localhost:3000](http://localhost:3000)**

## 📂 โครงสร้างโฟลเดอร์ (Directory Structure)
* `server/` — โค้ดฝั่งเซิร์ฟเวอร์ Express, AI Pipeline, ระบบจัดเก็บข้อมูล และ Fate Engine
* `public/` — โค้ดฝั่งไคลเอนต์ (HTML, CSS, JS) หน้าจอคุยไอ
* `data/` *(Git Ignored)* — โฟลเดอร์เซฟสำหรับการประมวลผลและการเล่นเกมในเครื่อง
* `prompt ai/` — พิมพ์เขียวคำสั่งวิเคราะห์ระบบกลไกและการเขียนร้อยแก้ว (Prose Craft)
* `.env` *(Git Ignored)* — ไฟล์เก็บรหัสลับสำหรับการเชื่อมต่อ DeepSeek API
